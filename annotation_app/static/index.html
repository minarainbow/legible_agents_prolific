Agent Action Annotation

You'll be watching an AI computer-use agent

A computer-use agent is an AI that operates a real computer on its own — moving the mouse, clicking, typing, and scrolling — to carry out a task a person gave it, much like a human would.

In this study you'll watch screen recordings of one of these agents working, and tell us — step by step — what it did. We're interested in how clearly people can follow what the agent is doing.

It will take about 20–30 minutes.

How it works

What you'll do

  1. For each recording, you'll first see the task the agent was asked to do.
  2. The recording plays and pauses after each action the agent takes.
  3. In your own words, write down what the agent just did in that step.
  4. Some steps are just the agent waiting — those are filled in for you automatically.
  5. At the end of each recording, you'll answer a few quick questions about how the agent did.
Two important rules

1. Be as specific as possible. Don't just write the type of action — say what the agent interacted with.

  • "clicked a button" → "clicked the File menu"
  • "typed something" → "typed report.pdf into the filename box"
  • "scrolled" → "scrolled down the Preferences list"
  • "right-clicked the desktop", "dragged the volume slider to the right"

2. Describe the agent's action, not the change on screen. Report what the agent did, not what appeared afterwards.

  • "a menu appeared" → "clicked the Edit menu"
  • "a window opened" → "double-clicked the Documents folder"

It's completely fine to answer "I can't tell what happened" when an action genuinely isn't clear — we're not testing your ability, and honest "can't tell" answers are valuable to us. We only ask that you don't select it just to get through faster.

Please work through each recording in one sitting. Your progress saves automatically in case of a disconnection.
